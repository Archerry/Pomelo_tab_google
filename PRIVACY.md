# Pomelo Tab Privacy Policy

Effective date: August 25, 2026
Last updated: August 25, 2026

Pomelo Tab is a local-first Chrome new-tab workspace. This policy explains what browser data Pomelo Tab handles, why it is needed, and the controls available to users.

## Data Pomelo Tab handles

After a user explicitly enables browser data access, Pomelo Tab handles:

- open-tab metadata, including page titles, URLs, tab and window identifiers, and favicons;
- bookmark titles and URLs;
- recent browsing-history titles, URLs, and visit dates;
- the domain of the active website and time spent on that domain, aggregated into local usage insights;
- information entered by the user, including an optional display name and custom shortcut names and URLs;
- preferences such as appearance and locally saved shortcuts.

Pomelo Tab does not read page contents, form contents, passwords, authentication cookies, personal communications, payment information, or health information.

## How the data is used

The data is used only to provide Pomelo Tab's single purpose: replacing the Chrome new-tab page with a workspace for tabs, bookmarks, recent history, shortcuts, search, and local browsing-usage insights.

Pomelo Tab does not use browser data for advertising, profiling, credit decisions, or any unrelated purpose.

## Local processing and storage

Browser data and preferences are processed locally and stored only in Chrome storage on the user's device. Pomelo Tab does not transmit this data to the publisher or to external servers.

Pomelo Tab does not sell, rent, share, or disclose user data to third parties. It does not execute remotely hosted code. Website icons are obtained through Chrome's built-in favicon API.

## Consent and user controls

Pomelo Tab displays a first-run disclosure before accessing tabs, bookmarks, browsing history, or the active website domain. These features remain paused until the user selects **Enable Pomelo Tab**.

Users can:

- select **Not now** to leave browser data access paused;
- pause browser data access later from Pomelo Tab Settings;
- clear locally stored usage insights from Settings;
- remove the extension to remove extension-managed local data according to Chrome's storage behavior.

## Data retention

Preferences, shortcuts, and usage aggregates remain in local Chrome storage until the user clears the applicable data, pauses access where offered, or removes the extension. Pomelo Tab does not retain a server-side copy.

## Chrome Web Store Limited Use

Pomelo Tab's use of information received from Chrome APIs is limited to providing and improving its disclosed single-purpose new-tab workspace and complies with the Chrome Web Store User Data Policy, including its Limited Use requirements.

## Changes to this policy

If Pomelo Tab's data practices change, this policy and the in-product disclosure will be updated before the new practices take effect where required.
