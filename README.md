# Pomelo New Tab

A private, local-first Chrome new tab workspace for open tabs, bookmarks, browsing history, shortcuts, and site-usage insights.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Load the generated `dist` directory from `chrome://extensions` with Developer mode enabled.

## Privacy

Pomelo stores preferences and usage statistics locally through Chrome Storage. It does not transmit or sell user data. See [PRIVACY.md](PRIVACY.md).
